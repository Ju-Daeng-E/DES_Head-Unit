# 변경사항

## 2025-11-05

- 블루투스 기능을 중앙 장치(Central)에서 주변 장치(Peripheral) 역할로 리팩토링했습니다.
- 이에 따라, 헤드유닛이 직접 블루투스 기기를 스캔하는 대신, 스마트폰과 같은 중앙 장치에서 헤드유닛을 찾아 연결할 수 있도록 변경되었습니다.

### 주요 변경 내용:

- **`BluetoothManager` 클래스 수정 (`src/backend/bluetooth/`):
  - 기기 검색(Discovery) 및 스캔(Scan) 관련 기능 (`QBluetoothDeviceDiscoveryAgent`, `startScan`, `stopScan` 등)을 모두 제거했습니다.
  - 헤드유닛이 블루투스 오디오 수신 장치(Audio Sink)임을 알리는 서비스 광고(Advertising) 기능을 추가했습니다.
  - 이제 헤드유닛은 외부 기기의 연결 요청을 수신 대기합니다.

- **블루투스 설정 화면 UI 수정 (`ui/pages/BluetoothScreen.qml`):
  - '사용 가능한 기기' 목록, '스캔' 버튼 등 기기 검색과 관련된 UI 요소들을 모두 제거했습니다.
  - 이제 UI는 페어링된 기기 목록과 현재 연결 상태만 표시하도록 단순화되었습니다.

- **버그 수정:
  - 이름이 없는 블루투스 기기가 스캔 목록에 표시되던 문제를 해결했습니다.
  - 이미 페어링된 기기가 앱 시작 시 목록에 나타나지 않던 문제를 수정했습니다.
